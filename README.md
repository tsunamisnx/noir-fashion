# NOIR — концептуальный сайт бренда одежды

Премиальный современный сайт концептуального бренда одежды в минималистичном тёмном стиле.

### Возможности

* 🖤 Премиальный тёмный дизайн
* 👕 Каталог одежды
* 🛍️ Карточки товаров
* 🔎 Удобная навигация
* ✨ Анимации и интерактивные элементы
* 📱 Адаптивная версия для мобильных устройств
* 🎨 Современная визуальная стилистика

### Технологии

HTML5
CSS3
JavaScript
Адаптивная вёрстка
